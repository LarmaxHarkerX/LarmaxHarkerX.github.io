# 关于这个个人站

我是 **唐辫小二 Larmax Harker**。这里用来放文章、生活碎片和自己的小项目。

## 可以逛什么

- [文章归档](/archive/)：长一点的记录、笔记和分享。
- [说说](/moments/)：不需要写成文章的日常想法。
- [项目](/projects/)：作品、实验和工具页面的入口。
- [相册](/albums/)：用照片记录生活。

## 当前状态

网站托管在 [GitHub Pages](https://larmaxharkerx.github.io/)，文章和配置通过 Git 管理，提交后由 GitHub Actions 自动构建与发布。三篇文章和两条友链已经迁入，主题自带的演示文章与系列说明已移入项目文档区归档。相册、项目等页面暂时保留主题示例，这些示例不代表站长的个人经历或作品。

头像、个人介绍和社交链接，可以在确定外观后继续补充。

我的 GitHub：[LarmaxHarkerX](https://github.com/LarmaxHarkerX)。

## 关于技术

网站使用 [Astro](https://astro.build/) 和 [Shirone](https://github.com/LyraVoid/Shirone) 主题构建，文章与说说使用 Markdown 保存，构建后可以部署到 GitHub Pages。
