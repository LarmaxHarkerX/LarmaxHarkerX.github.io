# Welcome to LARMAX Blog

This is a sample post that exists in the root of the posts directory, not inside any category folder.

## About This Blog

This blog is built with Vue 3 and features a Windows 3.1 style interface.

## Features

- Draggable windows
- Real folder navigation
- Markdown rendering
- Responsive design

## How to Navigate

1. Double-click folders to enter them
2. Double-click files to open them
3. Use the back button to go up a level
