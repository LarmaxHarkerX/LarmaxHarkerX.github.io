# Shirone 默认演示文档归档

此处保留主题自带的 22 篇 Markdown/MDX 示例、33 张配套图片和 2 份系列说明。文件从发布内容目录移来，正文未作改写，供以后查阅主题语法和用法。

- `posts/`：文章示例；`guide/` 和 `image-grid-demo/` 的相对图片资源一并保留。
- `series/`：原来的 Markdown 与媒体嵌入示例系列。

此目录不在 Astro 内容集合的扫描范围内，因此不会出现在首页、归档、分类、RSS 或全文搜索中，也不会生成原演示文章的访问路由。

示例中的站内链接、文件包含和 MDX 导入仍按原主题布局书写；这里保存的是源码参考，不是可独立运行的第二个网站。要重新发布某个示例，应先复制回 `src/content/posts/` 并核对它依赖的路径。

站点正式文章保存在 `src/content/posts/`，目前只有站长的三篇文章。
